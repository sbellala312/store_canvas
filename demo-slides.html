Ashley Furniture Industries · POC

Store Canvas

A visual floor-planning tool for designing store layouts — place real Ashley furniture, define zones, and export plans, all in the browser.

Overview

What is Store Canvas?

🎯 The Problem

Planning store layouts is slow, manual, and disconnected from the real product catalog.

💡 The Solution

An interactive canvas to drag real Ashley products onto scaled floor plans — with zones, measurements, and exports.

Implemented Live today

Plans & Catalog

🗂 Floor Plan Management
  • Create, edit, duplicate & delete multiple plans
  • Rectangular or polygon floor shapes
  • Per-plan persistence
🛋 Furniture Catalog (Live Data)
  • Live Azure Search — real SKUs, dimensions, prices, images
  • Search, filter & drag-and-drop placement
  • Kits — reusable furniture groupings
  • GLB tab + 3D model viewer
